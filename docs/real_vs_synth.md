# 실촬영 정상 주행과 합성 정상 운전 패턴 비교

`run_real_vs_synth.m`이 생성한 파일이다. 손으로 고치지 말 것. 생성: 2026-11-16

- 실촬영: DMS CSV(10 Hz)를 입력 단계(0점 보정 5초, 정면 범위 ±11° / ±13°)에 넣은 주시 판정. 보정 구간 5초는 뺀다. 얼굴 미검출은 이탈로 센다.
- 합성: `supervisor_b/normal_pattern` (미러 = 이탈). 평균은 seed 평균, 최장과 30 s 창 최대는 전체 seed의 최대.
- 실촬영은 촬영 프로토콜에 따라 시선 목표를 연달아 본 30~40초짜리 영상이다. 자연 주행보다 이탈이 촘촘하다는 점을 감안해서 읽는다.
- 이탈 비율과 30 s 창 누적은 주시 판정 그대로 센다. 횟수와 길이 통계는 0.2 s 미만 이탈(실촬영 10 Hz에서 1프레임짜리 각도 튐)을 빼고 센다. 합성에도 같은 규칙을 적용한다.
